# Jewel POS

Point-of-sale app for jewellery shops, for Windows.

## Download

Get the latest installer from the **[Releases page](https://github.com/malikHarisawan/jewel-pos/releases/latest)**:
download `Jewel-POS-Setup-<version>.exe` and run it.

Windows may show a SmartScreen warning the first time. Click **More info → Run anyway**.

## Updates

Once installed, the app checks this page for new versions on its own. When one is out it
shows **Update available**; nothing downloads until you press **Download & install**.

Your shop's data lives in `%APPDATA%\jewel-pos\` and is kept when you update or uninstall.

This repository only hosts the installers. The source code is private.
